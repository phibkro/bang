# caesar — encode/decode/round-trip cipher

Written by the round-1 **stranger-test** agent (docs/notes/stranger-test-1.md) from the
public docs alone — the first bang program authored by an outsider, preserved verbatim.
Exercises: `Str`/`Char` matching, nested `Char(n)` match, single- and multi-arg recursion,
thunks, `Left`/`Right` sums, arithmetic modular wrap, `concat`. Shifts assume `k ∈ 0..25`
(the author's own shipping note). No attribution comment in main.bang because bang has no
line comments yet (dogfood finding — this README exists partly for that reason).
