# Contributor feedback

**Summary:** Concrete papercuts and improvement opportunities observed while executing Plan 014. Evidence names the source; disposition prevents rediscovery.

| ID | Finding | Evidence | Impact | Disposition |
|---|---|---|---|---|
| F-001 | Architecture tools parsed classic `import` and silently ignored `public import`. | `tools/gen-import-graph.py:60`; former `tools/arch-check.sh:109`; 117 real internal edges become visible through `tools/import_facts.py`. | The generated graph reported almost all fan-in as zero, while the dependency gate passed without checking most edges. | **Fixed:** one shared import-fact parser is consumed by graph generation and dependency fitness. |
| F-002 | Unknown modules silently fell into Core in the graph generator. | Former `tools/gen-import-graph.py:82` used `TIER.get(m, "Core")`. | A restructure could produce plausible-looking but false architecture documentation. | **Fixed in Plan 014 seam:** path-derived classification fails loud on unknown modules. |
| F-003 | `Bang.Backend.Rung5ProofGrade` imported Apex-level `Bang.Spec`, violating the documented dependency V. | Former `Bang/Backend/Rung5ProofGrade.lean:5`; exposed only after F-001 was fixed. | A backend theorem alias depended outward on the public façade even though its proof already lives in `Backend.Wasm`. | **Fixed:** re-export `compile_forward_sim_proof` directly from the already-imported backend module; the V now holds across all parsed edges. |
| F-004 | The public Vocs source map publishes volatile project state beside stable learning material. | Former `web/docs/sync-docs.mjs`/`vocs.config.ts` root map and “Start here” navigation. | Newcomers cannot distinguish stable reference from time-indexed work; contradicts ADR-0077/ADR-0108. | **Fixed:** stable contributor routes remain public; `CONTEXT.md` and operational state stay repository-only. |
| F-005 | The graph generator’s own module doc still described the completed tier restructure as future work. | Former `tools/gen-import-graph.py:5-14`; generated `docs/architecture/core-overview.md` block. | The generator reproduced stale prose every time it repaired drift. | **Fixed in Plan 014:** generated captions describe only current extracted facts. |
| F-006 | Released tag `v0.1.1` still embeds and prints version `0.1.0`; `Main.lean` also says no tag has been cut. | `git show v0.1.1:Main.lean`; former `Main.lean:bangVersion`; release scripts lacked an identity comparison. | Release identity can disagree with the tag even though `bangVersion` is compiler provenance. | **Fixed:** provenance is source-pinned at `0.1.1`; `tools/check-release-version.sh` gates both pre-tag builds and stripped tagged artifacts, with known-bad fixture tests. |
| F-007 | The project dev shell cannot run the site’s pinned package-manager command. | `web/docs/bun.lock`, `web/docs/package.json`; the default Lean shell intentionally excludes Bun/Chromium. | A contributor can pass the Lean setup but cannot execute the production docs build without discovering an extra tool. | **Fixed:** opt-in `devShells.site` pins Bun + Chromium; `just site-build` is the one contributor/CI/release interface. |
| F-008 | The site build exits green when Mermaid rendering fails and silently replaces every diagram with a pointer note. | Former `renderMermaid` fallback plus broad emit-loop catches in `web/docs/sync-docs.mjs`. | CI can report a green docs build while the visual teaching layer is absent—the exact artifact the change intends to ship. | **Fixed:** production `build` is strict, render exceptions propagate, and Site/Pages/release gates all call `tools/site-build.sh`; fallback remains authoring-only. |
| F-009 | Root Markdown links into `docs/<section>/…` did not map to Vocs’s section routes. | Former `web/docs/sync-docs.mjs:rewriteLinks`; Vocs warned that new README/ONBOARDING architecture and ADR links were dead. | A repository link could be valid while its generated public-site projection was broken. | **Fixed:** the sync transform now maps repository `docs/<section>/x.md` paths to Vocs `/<section>/x` routes. |
